About This Project

This website was created as part of COS30045 Data Visualisation at Swinburne University of Technology[cite: 1].

The goal of this project is to build an interactive, data-driven web portal that communicates complex appliance energy usage data in an accessible format for everyday consumers[cite: 1].

Technology Stack

  • Frontend: Semantic HTML5, CSS3, and JavaScript
  • Data Processing: KNIME Analytics Platform[cite: 1]
  • Version Control: Git and GitHub Classroom[cite: 1]
