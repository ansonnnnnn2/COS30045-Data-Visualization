About This Project

This website was created as part of COS30045 Data Visualisation at Swinburne University of Technology.

The goal of this project is to build an interactive, data-driven web portal that communicates complex appliance energy usage data in an accessible format for everyday consumers.

About the Data

  • Data Source: The dataset is sourced from the official Australian Energy Rating database for consumer televisions, recording comparative physical measurements, display panel technologies, star ratings, and standardized annual kilowatt-hour (kWh/year) consumption figures.
  • Data Processing: Processed using KNIME Analytics Platform to eliminate invalid entries, filter active retail models, and convert diagonal measurements from centimetres to rounded inches for intuitive consumer evaluation.
  • Data Privacy & Ethics: The dataset comprises publicly available regulatory appliance test filings and contains no personal or sensitive individual records. Visualisations adhere to zero-baseline ethical reporting standards to avoid misleading representations.
